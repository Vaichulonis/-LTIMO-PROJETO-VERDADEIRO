## Site de mudanças climáticas:
# 🌎 Site sobre Mudanças Climáticas

Um site educativo desenvolvido com **Python, Flask e Jinja2** para explicar, de forma simples e acessível, o que são as **mudanças climáticas**, o que está sendo feito atualmente para combatê-las e quais hábitos podemos mudar para contribuir com um futuro mais sustentável.

## 📚 Sobre o projeto

As mudanças climáticas são alterações de longo prazo nos padrões de temperatura e clima do planeta. Atualmente, as atividades humanas, principalmente a queima de combustíveis fósseis, são uma das principais causas do aquecimento global.

O objetivo deste projeto é **informar e conscientizar** os visitantes sobre as mudanças climáticas, apresentando suas causas, consequências, formas de combate e atitudes que podem ser adotadas no dia a dia.

## 🌡️ O que o site apresenta:

### 🔥 O que são as mudanças climáticas?

Nesta seção, o visitante poderá aprender:

* O que são mudanças climáticas;
* O que é o efeito estufa;
* O que é o aquecimento global;
* Quais são os principais gases de efeito estufa;
* Como as atividades humanas contribuem para as mudanças climáticas;
* Quais são algumas de suas consequências.

### 🌱 O que está sendo feito para combatê-las?

O site apresenta algumas medidas utilizadas para enfrentar as mudanças climáticas, como:

* ☀️ Uso de fontes de energia renovável;
* 🌳 Preservação de florestas;
* 🚗 Redução das emissões de gases de efeito estufa;
* 🏙️ Adaptação das cidades aos impactos climáticos;
* 🌎 Cooperação entre países;
* ♻️ Incentivo a práticas mais sustentáveis.

Também será apresentado o papel de governos, empresas, organizações e da população no combate às mudanças climáticas.

### ♻️ O que podemos fazer?

O site apresenta hábitos que podem contribuir para um estilo de vida mais sustentável, como:

* 💡 Economizar energia;
* 🚲 Utilizar bicicleta ou caminhar quando possível;
* 🚌 Dar preferência ao transporte público;
* 🚗 Compartilhar caronas;
* 🥦 Evitar o desperdício de alimentos;
* 🛍️ Evitar o consumo desnecessário;
* ♻️ Reutilizar e reciclar materiais;
* 🌳 Preservar áreas verdes;
* 💧 Economizar água;
* 📢 Compartilhar informações confiáveis sobre o meio ambiente.

## 🎯 Objetivos do projeto

O projeto tem como principais objetivos:

1. Informar sobre as mudanças climáticas;
2. Explicar suas principais causas e consequências;
3. Apresentar medidas utilizadas para combatê-las;
4. Incentivar hábitos mais sustentáveis;
5. Utilizar a tecnologia como ferramenta de educação ambiental.

## 💻 Tecnologias utilizadas

O projeto será desenvolvido utilizando:

* **Python** — linguagem de programação;
* **Flask** — framework utilizado para desenvolver o servidor e gerenciar as rotas do site;
* **Jinja2** — sistema de templates utilizado pelo Flask para criar páginas HTML dinâmicas;
* **HTML5** — utilizado para estruturar as páginas;
* **CSS3** — utilizado para estilizar e organizar a interface.

## 🐍 Flask e Jinja2

O **Flask** será responsável pelo funcionamento do site, pelo gerenciamento das rotas e pela comunicação entre o servidor e as páginas.

O **Jinja2** será utilizado para criar templates reutilizáveis, permitindo compartilhar elementos como cabeçalho, menu de navegação e rodapé entre diferentes páginas.

Essa organização facilita a manutenção do projeto e evita a repetição desnecessária de código HTML.

## ⚙️ Como executar o projeto

### 1. Clone o repositório

Baixe ou clone este repositório para o seu computador.

Abra o terminal na pasta principal do projeto.

### 3. Instale o Flask

Instale o Flask utilizando o gerenciador de pacotes do Python.

### 4. Execute o projeto

Inicie a aplicação Flask através do arquivo principal do projeto.

### 5. Acesse o site

Após iniciar o servidor, acesse o endereço disponibilizado pelo Flask no navegador.

## 🌍 Importância do projeto

As mudanças climáticas representam um grande desafio ambiental da atualidade. Por isso, este projeto busca utilizar a tecnologia como uma ferramenta para facilitar o acesso à informação e incentivar atitudes mais sustentáveis.

O site procura mostrar que tanto grandes ações, realizadas por governos e organizações, quanto mudanças de hábitos no cotidiano podem fazer parte da resposta às mudanças climáticas.

> **Conhecer o problema é o primeiro passo para fazer parte da solução. 🌱**
